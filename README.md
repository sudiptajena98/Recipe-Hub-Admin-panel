# Recipe Hub Admin Panel

Recipe Hub Admin Panel is a web-based application built with **Next.js, TypeScript, and Tailwind CSS** to manage recipes, users, and favourites.

## Features
- Admin login
- Dashboard with statistics
- View, add, edit, and delete recipes
- Manage users and favourites
- Backend API integration using Node.js, Express.js, and MongoDB

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Technologies Used
- Next.js
- TypeScript
- Tailwind CSS
- Node.js and Express.js
- MongoDB
